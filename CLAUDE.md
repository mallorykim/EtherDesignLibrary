# CLAUDE.md

Agent guidelines for this repo live in **[AGENTS.md](AGENTS.md)** — a single source of truth
for all agents (Claude Code, Codex, etc.). Read and follow it.

Key rule (see AGENTS.md for the full version): for **any** component work — creating,
rebuilding, or reviewing — if an official WinUI control's architecture/template/skeleton can be
copied and reskinned, **copy the skeleton and swap the skin; do not write it from scratch.**
Always reference the official sources first: WinUI-Gallery
(https://github.com/microsoft/WinUI-Gallery) and microsoft-ui-xaml
(https://github.com/microsoft/microsoft-ui-xaml).
